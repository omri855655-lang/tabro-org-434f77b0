# ZoneFlow room atmosphere refresh

The room panel now gives the scene more space: camera and activity controls remain available, design settings collapse, and Quiet view hides optional controls without unmounting the room or its timer. Start/pause/reset and leaving the room remain accessible. New controls have copy in Hebrew, English, Spanish, Chinese, Arabic and Russian.

All twelve atmospheres receive a separate crafted detail layer. Reading rooms use cornices, sconces, book details, a small-library fireplace or large-hall chandeliers. Cafes add bar fronts, grinders, cups and pastry displays. Cabins add vent panels, lighting lenses, carpet detail and galley cabinetry. Offices and modern libraries use ceiling slats and storage; the terminal adds gate fixtures. The detail layer is merged by material to limit draw calls. The existing avatar design encoding, personal editor, movement, activities and presence payloads are preserved; meshes add rounded clothing, shoes and face details.

Outdoor windows share a panoramic render target with cropped UVs, layered garden/courtyard/street/apron geometry, moving trees/clouds/traffic, and optional rain. The existing local forest HDR supplies distant detail where appropriate, with geometric fallback if unavailable. Async furniture loading no longer overwrites live window materials. Aircraft retain their existing wing/runway scene and timer-driven ascent, now with updated day/golden-hour/night and overcast lighting.

Automatic ambience follows the device's local clock: daylight 07:00-17:00, golden hour 17:00-20:00, night otherwise. These are ambience presets, not geolocated sunrise/sunset or live weather. Users can override the phase and choose clear/rain. Settings are local visual preferences; room membership and other participants are unchanged. Dynamic outdoor rendering is limited to six updates per second, pauses with the room-life toggle or reduced-motion preference, and skips hidden browser tabs. Flight motion continues to follow the focus timer. Detailed rendering uses up to 2x device resolution, bounded by a 2.8-million-pixel target for normal viewport sizes.

Detailed book sets use distance-aware geometry: scanned books remain nearby, while distant shelves use a 168-triangle row instead of the 67,306-triangle source set. Switching has distance hysteresis; phone-sized canvases use a shorter detail distance. Reading lamps, cups and plants stay visible when imported furniture replaces procedural tables and chairs.

Final local verification after integrating cloud QA fixes: all 215 application tests passed. App TypeScript, targeted ESLint for changed room code and the production build passed. The build retains existing large-chunk and mixed-import warnings. Tests cover clock boundaries, stored-value parsing, pixel budget, portrait field of view, every crafted room's geometry/batching/disposal, shared outdoor targets, correctly proportioned window crops, frozen animation, lighting changes, restoration, distance-aware shelf geometry and late async asset handling. Existing seating, movement, avatar encoding and presence regressions remain covered.

Cloud visual QA covered all twelve atmospheres on desktop and portrait phone viewports, with sampled cinematic scenes and lighting/weather combinations, camera controls, walking, seating and quiet-view timer continuity. See `2026-10-24-room-visual-qa.md` for exact coverage and fixes. Cloud QA preceded the distance-aware shelf optimization; the merged code passed the final local checks above. Publication is a separate step and is not established by these tests.

Physical iPhone performance, two-account realtime testing and visual parity with FocusTown are not established. The sandbox's software WebGL was slow; the distance-aware shelf optimization reduces geometry but is not a measured real-device FPS guarantee. Cafe pendant silhouettes and stronger differentiation between cabin/cafe variants remain visual follow-ups. These remain real-time stylized environments with detailed assets, not scanned photorealistic interiors.
